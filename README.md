# Prédiction des prix agricoles en Tunisie

Projet de Machine Learning visant à prédire les prix des produits agricoles en Tunisie à partir de données historiques, afin d'anticiper leurs variations selon le produit, la région et la saison.

## Démarche

1. **Analyse des données** : exploration des séries de prix historiques par produit, région et période.
2. **Préparation des features** : construction de variables pertinentes (produit, région, saisonnalité) à partir des données brutes.
3. **Entraînement de plusieurs modèles** : comparaison de différentes approches de machine learning pour identifier la plus performante.

## Technologies

Python, Pandas, Scikit-learn, Matplotlib, Jupyter
